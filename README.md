# 💰 청년 금융 건강 AI

청년 사용자의 금융 상태를 진단하고,
금융 위험요인과 미래 자산 변화를 시각화하여
더 나은 금융 의사결정을 돕는 AI 기반 금융 건강 관리 서비스입니다.

---

## 📌 프로젝트 소개

청년들은 소득, 지출, 저축, 부채 등 다양한 금융정보를 가지고 있지만
현재 자신의 금융상태가 안정적인지 판단하기 어렵습니다.

본 프로젝트는 사용자의 금융 데이터를 기반으로

- 현재 금융상태 진단
- 금융 위험점수 및 건강점수 계산
- 주요 위험요인 설명
- 12개월 금융자산 전망
- What-if 금융 시뮬레이션

을 제공하여 사용자가 자신의 금융상태를 쉽게 이해하고
금융 행동 변화에 따른 결과를 직접 확인할 수 있도록 합니다.

---

## 🎯 핵심 목표

단순히 현재 금융상태를 보여주는 금융 계산기가 아니라,

> 사용자의 금융상태를 설명하고  
> 금융 행동 변화가 미래에 어떤 영향을 주는지 보여주는  
> 청년 금융 의사결정 지원 서비스

를 구현하는 것을 목표로 합니다.

---

## 👤 사용자 입력 정보

현재 MVP에서는 다음 6가지 금융정보를 입력받습니다.

- 월 소득
- 월 고정지출
- 월 생활비
- 월 대출상환액
- 월 저축금액
- 현재 저축액

테스트를 위해 안정 / 주의 / 위험 사용자 예시 프로필도 제공합니다.

---

## 🔍 주요 기능

### 1. 금융 현금흐름 분석

월 소득과 지출, 저축 계획을 비교하여
매월 남는 금액 또는 부족한 금액을 계산합니다.

### 2. 금융 건강 진단

다음과 같은 금융지표를 계산합니다.

- 월 잉여금
- 저축률
- 부채상환 비율
- 비상자금 보유 수준

### 3. 금융 위험점수 및 건강점수

금융지표를 기반으로 위험도를 계산하고
사용자가 직관적으로 이해할 수 있도록 금융 건강점수를 제공합니다.

금융 상태는 다음과 같이 구분합니다.

- 🟢 안정
- 🟡 주의
- 🔴 위험

위험점수 산정은 규칙 기반 금융 위험 분석 엔진을 사용합니다.

### 4. 주요 위험요인 설명

사용자의 금융 상태에서 발견된 주요 위험요인을
문장 형태로 제공합니다.

예:

- 비상자금이 부족합니다.
- 저축 여력이 부족합니다.
- 부채상환 부담이 높습니다.

### 5. 12개월 금융자산 전망

현재 저축액과 월 저축금액을 기반으로
향후 12개월 동안 예상되는 금융자산 변화를 시각화합니다.

### 6. What-if 시뮬레이션

사용자가 직접

- 생활비 절감
- 소득 증가

조건을 변경하면서 금융 건강점수와
12개월 예상자산이 어떻게 변하는지 확인할 수 있습니다.

이를 통해 금융 행동 변화가 미래에 미치는 영향을
직접 비교할 수 있습니다.

---

## 🧠 시스템 구조

```text
사용자 금융정보 입력
        ↓
금융지표 계산
(metrics.py)
        ↓
금융 위험 분석
(risk_engine.py)
        ↓
금융 건강점수 / 위험요인
        ↓
12개월 전망
(forecast.py)
        ↓
What-if 시뮬레이션
        ↓
Streamlit 대시보드
```
