# 💰 청년 금융 건강 AI - MONEYFIT

청년 사용자의 금융 상태를 진단하고,

금융 위험요인과 미래 자산 변화를 시각화하여

더 나은 금융 의사결정을 돕는 **AI 기반 금융 건강 관리 서비스**입니다.

---

## 📌 프로젝트 소개

청년들은 소득, 지출, 저축, 부채 등 다양한 금융정보를 가지고 있지만

현재 자신의 금융상태가 안정적인지 판단하기 어렵습니다.

**MONEYFIT**은 사용자의 금융 데이터를 기반으로

- 현재 금융상태 진단
- 금융 위험점수 및 건강점수 계산
- 주요 위험요인 설명
- 12개월 금융상태 및 자산 전망
- What-if 금융 시뮬레이션
- 개인별 자동 개선계획 제안
- 실제 금융상품 추천
- AI 금융코치 질의응답

을 제공하여 사용자가 자신의 금융상태를 쉽게 이해하고

금융 행동 변화에 따른 결과를 직접 확인할 수 있도록 합니다.

---

## 🎯 핵심 목표

단순히 현재 금융상태를 보여주는 금융 계산기가 아니라,

> 사용자의 금융상태를 진단하고  
> 위험 원인을 설명하며  
> 금융 행동 변화가 미래에 어떤 영향을 주는지 보여주고  
> 실제 실행 가능한 개선 방향까지 제안하는  
> **청년 금융 의사결정 지원 서비스**

를 구현하는 것을 목표로 합니다.

---

## 👤 사용자 입력 정보

현재 MVP에서는 다음 6가지 금융정보를 입력받습니다.

- 월 소득
- 월 고정지출
- 월 생활비
- 월 대출상환액
- 월 저축금액
- 현재 저축액

빠른 테스트를 위해

- 안정
- 주의
- 위험

사용자 예시 프로필도 제공합니다.

---

## 🔍 주요 기능

### 1. 💵 금융 현금흐름 분석

월 소득과 고정지출, 생활비, 대출상환액, 저축금액을 비교하여

매월 실제로 남는 금액 또는 부족한 금액을 계산합니다.

주요 지표:

- 월 잉여금
- 저축률
- 부채상환 비율
- 생활지출 비율
- 비상자금 보유 수준

---

### 2. 🩺 금융 건강 진단

사용자의 금융지표를 기반으로 현재 금융상태를 분석합니다.

분석 결과:

- 금융 건강점수
- 금융 위험점수
- 위험등급
- 주요 진단 사유

금융 상태는 다음과 같이 구분합니다.

- 🟢 안정
- 🟡 주의
- 🔴 위험

위험점수 산정은 **규칙 기반 금융 위험 분석 엔진**을 사용합니다.

---

### 3. 🔎 영역별 위험요인 분석

사용자의 금융상태를 여러 영역으로 나누어

어떤 부분이 취약한지 확인할 수 있습니다.

분석 영역:

- 현금흐름
- 부채
- 저축
- 비상자금
- 지출구조

예:

- 비상자금이 부족합니다.
- 지출과 저축 후 남는 여유자금이 부족합니다.
- 생활지출 부담이 높은 편입니다.
- 부채상환 부담이 높습니다.

---

### 4. 📈 12개월 금융 전망

현재 금융상태를 유지했을 때

향후 12개월 동안의 금융상태 변화를 확인할 수 있습니다.

주요 결과:

- 12개월 금융 건강점수 전망
- 예상 금융자산 변화
- 현재 행동 유지 시 결과
- 개선안 적용 시 결과 비교

현재 금융정보와 현금흐름을 기반으로 한

**시나리오 기반 전망 방식**을 사용합니다.

---

### 5. 🔄 What-if 금융 시뮬레이션

사용자가 직접 금융 행동을 변경하면서

금융상태가 어떻게 달라지는지 확인할 수 있습니다.

변경 가능한 조건:

- 생활비 절감
- 소득 증가
- 추가 저축

조건을 변경하면

- 금융 건강점수
- 위험점수
- 월 잉여금
- 예상 금융자산

변화를 즉시 비교할 수 있습니다.

이를 통해 사용자는

**“지금 무엇을 바꾸면 가장 효과가 큰가?”**

를 직접 확인할 수 있습니다.

---

### 6. 🎯 자동 개선계획

현재 금융상태를 기반으로

실행 가능한 개선안을 자동으로 탐색합니다.

개선계획은 다음 유형으로 제공합니다.

- 부담 최소형
- 균형형
- 개선 효과형

각 개선안별로

- 예상 금융 건강점수
- 예상 위험점수
- 예상 위험등급
- 월 잉여금
- 12개월 예상 결과

를 비교할 수 있습니다.

---

### 7. 🏦 맞춤 금융상품 추천

금융감독원 금융상품 API를 연동하여

실제 예금·적금 상품 정보를 조회합니다.

사용자의 금융상태와 현금흐름을 바탕으로

적합한 금융상품을 추천합니다.

주요 기능:

- 실제 예금상품 조회
- 실제 적금상품 조회
- 상품별 금리 및 조건 확인
- 금융상태 기반 추천

단, 현금흐름이 부족한 위험 사용자의 경우

무리한 금융상품 가입보다 **현금흐름 개선을 우선**하도록 설계했습니다.

---

### 8. 🤖 AI 금융코치

AI 금융코치는 사용자의 금융 진단 결과와

자동 개선계획을 바탕으로 맞춤형 설명을 제공합니다.

사용자는 자신의 금융상태에 대해 자유롭게 질문할 수 있습니다.

예:

- 지금 가장 먼저 바꿔야 할 금융습관은?
- 왜 현금흐름이 위험한가요?
- 비상자금을 늘리려면 어떻게 해야 하나요?
- 어떤 개선안을 선택하는 것이 좋나요?

AI는 금융점수를 직접 계산하지 않고,

**기존 금융 계산 엔진이 산출한 결과를 기반으로 설명하는 역할**을 담당합니다.

이를 통해 생성형 AI가 임의의 금융수치를 만들어내는 문제를 줄였습니다.

## ▶️ 실행 방법

### 1. 저장소 클론

```bash
git clone https://github.com/syj318/youth-finance-ai.git
cd youth-finance-ai
```

### 2. 가상환경 생성

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. 라이브러리 설치

```bash
pip install -r requirements.txt
```

### 4. 환경변수 설정

프로젝트 루트에 `.env` 파일을 생성합니다.

```env
GROQ_API_KEY=YOUR_GROQ_API_KEY
GROQ_MODEL=openai/gpt-oss-20b
FSS_FINLIFE_API_KEY=YOUR_FSS_API_KEY
```

실제 API Key는 GitHub 저장소에 업로드하지 않습니다.

### 5. 실행

```bash
python -m streamlit run streamlit_app.py
```

## ✨ MONEYFIT의 차별점

### 1. 단순 금융 계산기가 아닌 의사결정 지원 서비스

현재 상태를 보여주는 것에서 끝나지 않고

```text
진단
↓
위험 원인 분석
↓
미래 전망
↓
What-if 시뮬레이션
↓
개선계획
↓
실제 금융상품 추천
↓
AI 금융코칭
```

까지 하나의 흐름으로 제공합니다.

### 2. 금융 계산과 생성형 AI의 역할 분리

금융점수와 위험등급은 자체 금융 분석 로직이 계산하고,

AI는 계산된 결과를 설명합니다.

### 3. 실제 금융상품 데이터 활용

임의로 생성한 금융상품이 아니라

금융감독원 API에서 제공되는 실제 예금·적금 데이터를 활용합니다.

### 4. 행동 변화의 효과를 직접 확인

생활비 절감, 소득 증가, 추가 저축 등의 행동이

사용자의 금융 건강점수와 미래 자산에 어떤 영향을 주는지

What-if 시뮬레이션으로 확인할 수 있습니다.
